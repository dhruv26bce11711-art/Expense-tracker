# Project Statement

## Problem Statement
Managing everyday expenses manually can make it difficult to know how much money has been spent, where it was spent, and which expenses are the largest. The Smart Expense Tracker provides a simple command-line solution for recording and analyzing expenses.

## Scope
The current project focuses on local, in-memory expense management without a database. It supports creation, viewing, searching, analysis and deletion of expenses during a program session.

## Target Users
- Students
- Individuals tracking daily spending
- Beginners learning Python programming and data structures

## High-Level Features
- Expense entry
- Expense listing
- Total calculation
- Category-wise analysis
- Search
- Highest-expense identification
- Monthly summary
- Expense deletion
